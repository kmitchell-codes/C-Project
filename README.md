# C-Project
Journal Entry
• What was the problem you were solving in the projects for this course?
The main problem I was solving involved using algorithms to store and retrieve data effectively. For example, I needed to be able to print out a list of courses in alphanumeric order, which required selecting the right structure and logic to make that happen efficiently.
• How did you approach the problem? Why are data structures important to understand?
I approached the problem by first analyzing what the project required, then reviewing the different types of data structures to decide which one would work best for those needs. Understanding data structures is important because each one has its own strengths and weaknesses. Choosing the right one can make your program faster, easier to manage, and more reliable.
• How did you overcome any roadblocks during the activities or the project?
Whenever I hit a roadblock, I utilized different resources, online guides, videos, and examples to figure out how to move forward. I also tried breaking the problem down into smaller steps, which helped me understand and solve each piece without getting overwhelmed.
• How has your work on this project expanded your approach to designing software and developing programs?
This project helped me understand the importance of writing clear, organized pseudocode before jumping into actual code. It also showed me how different algorithms work behind the scenes and why choosing the right one can make a big difference depending on what you're trying to achieve.
• How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
I've definitely gained a better appreciation for clean and reusable code. I see now why it's so important to write programs that others can understand and modify if needed. Planning things out and keeping your code tidy not only helps avoid confusion, but also makes it easier to update or scale down the line.

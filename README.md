# C++ Course Planner

**SNHU CS 300 | Data Structures and Algorithms**

A console-based advising tool that loads course records from a CSV file, prints an alphanumerically sorted course list, and displays a selected course's prerequisites.

## Technologies and features

- C++, `std::unordered_map`, vectors, sorting, file I/O, CSV parsing
- Store and retrieve course details by course number
- Sort and display the complete course list
- Search for a course and show its prerequisites
- Console menu for loading, viewing, and searching

## Files and running notes

- [ProjectTwo.cpp](ProjectTwo.cpp): main application
- [ProjectTwo.sln](ProjectTwo.sln): Visual Studio solution

**Input file needed:** The code expects `CS 300 ABCU_Advising_Program_Input.csv` in the working directory. That file is not included in this repository, and the filename is hard-coded.

## Development process and lessons learned

### The problem I was solving
The main problem I was solving involved using algorithms to store and retrieve data effectively. For example, I needed to be able to print out a list of courses in alphanumeric order, which required selecting the right structure and logic to make that happen efficiently.
### Choosing data structures
I approached the problem by first analyzing what the project required, then reviewing the different types of data structures to decide which one would work best for those needs. Understanding data structures is important because each one has its own strengths and weaknesses. Choosing the right one can make your program faster, easier to manage, and more reliable.
### Overcoming roadblocks
Whenever I hit a roadblock, I utilized different resources, online guides, videos, and examples to figure out how to move forward. I also tried breaking the problem down into smaller steps, which helped me understand and solve each piece without getting overwhelmed.
### How the project changed my approach
This project helped me understand the importance of writing clear, organized pseudocode before jumping into actual code. It also showed me how different algorithms work behind the scenes and why choosing the right one can make a big difference depending on what you're trying to achieve.
### Maintainability
I've gained a better appreciation for clean and reusable code. I see now why it's so important to write programs that others can understand and modify if needed. Planning things out and keeping your code tidy not only helps avoid confusion, but also makes it easier to update or scale down the line.
